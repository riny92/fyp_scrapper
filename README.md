# fyp_scrapper
 
## 26/01/2025
- Scraper tool has functionality to target Arxive as data source. It has the ability to target any of the 'categories' available on the webpage (ie. cs, math, stat, etc), and scrap a number of results specified by user for each category. Data is processed in a json file and metadata labeled accordingly.
- Could use improvement in text handling, such as spacing, paragraphs etc.
- Added a main.py (empty for now) for further centralisation of the scrapper (ie when more functionalities are added etc)
